## 🧭 Философия и Концепция

**Система Аньянова** — это научно выверенная система невербальной калибровки человека через синергию гардеробных слоев ($L1–L4$) и ольфакторной физики нишевой парфюмерии. 

В основе системы лежит **двумерная фазовая плоскость координат**, объединяющая 8 ключевых измерений человеческого позиционирования:

```
                  ВЕРХ: ОТНОШЕНИЕ К СЕБЕ (Внутренний контур)
             [Настроение • Тонус • Самоощущение • Диффузия]
                                     ▲
                                     │  (Ось Y: День / Лето / Холод)
   ЛЕВО: ДИСТАНЦИЯ                   │                   ПРАВО: СБЛИЖЕНИЕ
  [Субординация / Фокус] ◄───────────┼───────────► [Эмпатия / Интим]
 (Ось X: Власть / Formal)            │            (Ось X: Соблазн / Casual)
                                     │  (Ось Y: Вечер / Зима / Тепло)
                                     ▼
                   НИЗ: ОТНОШЕНИЕ К ОБЩЕСТВУ (Внешний контур)
                [Власть • Статус • Социальный вес • Шлейф]
```

### Два горизонта матрицы:

1. **✨ Верхний горизонт: НАСТРОЕНИЕ ($Y > 0$, Отношение к себе)**
   * **Северо-Запад ($X < 0$): Фокус и Дисциплина.**  
     Выглаженный хлопок сорочки, структурированный блейзер, ледяной цитрон и сухой ирис. Максимальная ясность ума и аналитический контроль.
   * **Северо-Восток ($X > 0$): Дневная Лёгкость.**  
     Дышащий лен, расстегнутый ворот, светлая гамма, морская акватика и бергамот. Внутренняя свобода, открытость и энергия солнца.

2. **👑 Нижний горизонт: ВЛАСТЬ ($Y < 0$, Отношение к обществу)**
   * **Юго-Запад ($X < 0$): Твёрдая Власть (Hard Power).**  
     Тяжелая костюмная шерсть, плотное прямое пальто, полированные оксфорды, темный уд и дымная кожа. Непререкаемый авторитет, иерархический вес и статус.
   * **Юго-Восток ($X > 0$): Мягкая Власть (Soft Power / Соблазн).**  
     Тактильный кашемир, замша, глубокий темный трикотаж, согревающий кардамон, табачный лист и стручковая ваниль. Власть магнетизма, притяжения и шарма.

## ⚙️ 8 Фундаментальных измерений

| Измерение | Ось в системе | Влияние на компилятор |
| :--- | :--- | :--- |
| **1. Диффузия** | Вертикаль (полюс $+Y$) | Летучесть аромата: от взрывного цитрусового бриза до интимного звучания |
| **2. Температура** | Слайдер окружения (-15°C…+35°C) | Выбор плотности тканей и комплектации слоев ($L1–L4$) |
| **3. Время суток** | Ось $Y$ (День ◄► Вечер) | Баланс между функциональным светом и вечерней глубиной |
| **4. Сезон** | Ось $Y$ (Лето ◄► Зима) | Сезонная фильтрация фактур (лён/хлопок vs фланель/шерсть/кашемир) |
| **5. Настроение** | Верхний ярус ($Y > 0$) | Внутреннее психоэмоциональное состояние (Фокус vs Лёгкость) |
| **6. Дистанция** | Ось $X$ (Обособленность ◄► Сближение) | Социальная дистанция взаимодействия с окружающими людьми |
| **7. Формальность** | Индекс $FI 1–3$ и края оси $X$ | Строгость силуэта: Casual (1), Smart Casual (2), Business Formal (3) |
| **8. Власть** | Нижний ярус ($Y < 0$) и левый край оси $X$ | Степень невербального доминирования: авторитет статуса или сила соблазна |

## 🚀 Возможности приложения

* **Interactive Anyanov Board**: Интерактивная координатная доска с мгновенным откликом на клик/drag, динамической подсветкой ярусов и квадрантов.
* **Wardrobe OS Mannequin**: Визуализатор 4-слойной архитектуры гардероба ($L4$ Верхняя одежда, $L3$ Торс, $L2$ Брюки, $L1$ Обувь) с цветовыми кодами и подсказками ткани.
* **Fragrance Mirror**: Автоматический подбор парфюмерного дуэта с расчетом совместимости (90–100%), полной ольфакторной пирамидой (Верх, Сердце, База) и расшифровкой синергии.
* **Precision Tuning**: Плавные слайдеры для точной доводки социальной дистанции, времени суток, формальности ($FI$) и уличной температуры.
* **1-Click Presets**: Готовые сценарии: *Стратегические переговоры*, *Летняя терраса*, *Романтическое свидание*, *Офисный Smart Casual*, *Зимний закрытый клуб*.
* **Манифест Системы**: Философский фундамент и принципы элегантности без ошибок и лишних усилий.

## 📦 Установка и быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/vsanyanov-ux/system-anyanov.git
   cd system-anyanov
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки:**
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:5173](http://localhost:5173) в браузере.

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```

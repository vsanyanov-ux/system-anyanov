## 🧭 Философия и Концепция

**Система Аньянова** — это прикладная система невербальной калибровки человека через синергию 4 гардеробных слоев ($L1–L4$), ольфакторной физики нишевой парфюмерии и персонального гардероба ароматов.

> **Главный закон применения стиля:**  
> Человек не начинает день с поиска одежды под случайный флакон духов. Человек сначала понимает контекст (куда он идёт) и надевает одежду ($L1–L4$). А парфюм — это **завершающий штрих**, который либо ставит печать уверенности на весь образ, либо разрушает его. Поэтому система подбирает аромат **строго из личной полки пользователя**, проверяя синергию с собранным луком.

В основе системы лежит **двумерная фазовая плоскость координат**, выражающая каноническую матрицу **Импрессионики 5 × 5** (10D-базис цели и контекста):

```
                  ВЕРХ: КОНТЕКСТ СРЕДЫ (Свет, Динамика, Стихия)
               [Лето • Холод • День • Outdoor (Улица) • Спринт]
                                      ▲
                                      │  (Ось Y: Хронотоп и физика среды)
    ЛЕВО: БРОНЯ И СТАТУС              │              ПРАВО: СБЛИЖЕНИЕ И ЭРОС
   [Обособленность / Formal] ◄────────┼────────► [Интимность / Casual]
  (Власть / Фокус / Statement)        │          (Соблазн / Лёгкость / Quiet)
                                      │  (Ось Y: Покой, Глубина, Контроль)
                                     ▼
                   НИЗ: КОНТЕКСТ СРЕДЫ (Гравитация, Зал, Длительность)
               [Зима • Тепло • Вечер • Indoor (Зал) • Марафон]
```

> **Принцип ортогональности Импрессионики:**  
> Плотность ткани (г/м) и скорость диффузии молекул парфюма не являются координатными осями цели — это **выходные каналы материального синтеза**. Точка на координатной сетке определяет цель, а ткань и парфюм подбираются компилятором как её материальные носители.

### Два горизонта матрицы:

1. **✨ Верхний горизонт: НАСТРОЕНИЕ ($Y > 0$, Отношение к себе)**
   * **Северо-Запад ($X < 0$): Фокус и Дисциплина.**  
     Выглаженный хлопок сорочки, структурированный блейзер, ледяной цитрон и сухой ирис. Максимальная ясность ума и аналитический контроль.
   * **Северо-Восток ($X > 0$): Дневная Лёгкость.**  
     Дышащий лен, расстегнутый ворот, светлая гамма, морская акватика и бергамот. Внутренняя свобода, открытость и энергия солнца.

2. **👑 Нижний горизонт: ВЛАСТЬ ($Y < 0$, Отношение к обществу)**
   * **Юго-Запад ($X < 0$): Твёрдая Власть (Hard Power).**  
     Тяжелая костюмная шерсть, плотное прямое пальто, полированные оксфорды, темный уд и дымная кожа. Непререкаемый авторитет, иерархический вес и статус.
   * **Юго-Восток ($X > 0$): Мягкая Власть (Soft Power / Соблазн).**  
     Тактильный кашемир, замша, глубокий темный трикотаж, согревающий кардамон, табачный лист и стручковая ваниль. Власть магнетизма, притяжения и шарма.

## 🚀 Ключевые модули

### 1. 🧭 Матрица Брендов 1–3–5–9 & Кросс-Радар Аналогов (Глава 5.2)
* **Математическая формула 1–3–5–9**: разложение любого мирового парфюмерного дома по ступеням зрелости гардероба:
  - **1 (Камертон Баланса $0,0$):** единственный внесезонный флакон на 80% гардеробных задач (*Versace Dylan Blue*, *Tom Ford Grey Vetiver*, *Lattafa Fakhar Black*).
  - **3 (Триада Жизни: Баланс + Офис NW + Соблазн SE):** сохранение Камертона (0,0) как универсального ядра + холодная дисциплина офиса днем ($-X$) + теплый магнетизм и чувственное сокращение дистанции вечером ($+X$).
  - **5 (Квинтет Стихий):** полное закрытие всех 4 квадрантов матрицы Аньянова (Центр, NE Лето, NW Офис, SW Власть, SE Соблазн).
  - **9 (Палитра Полутонов):** перекрытие всех климатических переходов (весенний озон, летний зной, бархатная осень, морозная зима).
* **Кросс-брендовый спарринг (Люкс vs Ниша vs Smart Dupe)**: прямое сопоставление *Versace*, *Tom Ford* и *Lattafa* слот-в-слот с расчетом дистанции соответствия $\Delta$.
* **Интерактивный 2D-радар**: визуализация точек ароматов на фазовой плоскости с мгновенной примеркой лука в 1 клик.

### 2. 🧪 Интеллектуальный Детектор Клонов и Смарт-Аналогов (Clone Finder)
* **Многоуровневый алгоритм сопоставления (`src/engine/cloneFinder.ts`)**:
  - **10D Сольфеджио Стиля**: вычисление косинусного сходства $\cos(\theta)$ и взвешенной евклидовой дистанции между ольфакторными профилями.
  - **2D Дельта Аньянова**: точечная посадка на фазовой плоскости с дельтой $\Delta = \sqrt{\Delta X^2 + \Delta Y^2}$.
  - **Пирамидальное подобие**: взвешенный анализ нот (Top, Heart, Base) и отсечение поверхностного сходства.
* **Гармоническая классификация**:
  - **UNISON ($\Delta < 0.15$)**: структурный аналог с идентичным раскрытием и шлейфом.
  - **CONTRAPUNCT ($\Delta \in [0.15, 0.4]$)**: близкий аналог с авторской вариацией и контрастными акцентами.
  - **DIVERGENCE ($\Delta > 0.4$)**: ароматическое расхождение.
* **Быстрый доступ к культовым эталонам**: мгновенный подбор смарт-дупов для *Aventus*, *Angels' Share*, *Tobacco Vanille*, *Baccarat Rouge 540*, *Ganymede*, *Lost Cherry*, *Sauvage*, *Tuscan Leather*, *Bleu de Chanel*, *Fahrenheit*, *Encre Noire*, *Soleil Blanc*.
* **Прямая интеграция**: моментальная примерка аромата на виртуальный манекен и добавление на личную полку в 1 клик.

### 3. 🏛️ Двухуровневый ритейл-интерфейс («Для жизни» vs «Витрина категории»)
* **Режим консьержа (Топ-2, по умолчанию):**
  - Полное устранение парадокса выбора: система выдаёт ровно **1 Чемпиона** + **1 Контрастного дублёра** под ситуацию.
  - Разбор 3 ключевых факторов победы аромата (социальная цель, тканевый резонанс со слоями $L1–L4$, физика диффузии).
  - Автоматический детектор ольфакторных брешей гардероба (*Wardrobe Gap*).
* **Режим витрины категории (Искушенный покупатель / Ритейл):**
  - Под **ту же самую ситуацию** в 1 клик разворачивается витрина всех квалифицированных ароматов категории.
  - Фильтры по брендам (*Versace, Tom Ford, Chanel, Dior, Hermès, Creed...*), текстовый поиск по нотам (*«ветивер»*, *«уд»*, *«ирис»*).
  - Интерактивная кнопка **«Надеть этот аромат»**: флакон примеряется на текущий комплект одежды, пересчитывая резонанс.

### 4. ⚡ Облачный бэкенд Supabase (Cloud Registry, Shelves & Analytics)
* **Глобальный каталог ароматов (PostgreSQL):** облачный реестр проверенных формул и пользовательских флаконов.
* **Синхронизация полок:** сохранение и бесшовный доступ к личной полке с любого устройства.
* **Анонимная аналитика поводов:** сбор запросов пользователей для выявления трендов и обогащения парсера.
* **Offline-First Resilience:** прозрачная и безотказная работа через `localStorage` в отсутствие сети или ключей.

### 5. 🧴 Моя парфюмерная полка (Fragrance Wardrobe Shelf)
* **Никакого ручного ввода нот:** пользователю не нужно изучать химию пирамиды.
* **Выбор флаконов в 1 клик:** библиотека из 50+ культовых, нишевых, люксовых и отечественных ароматов (Chanel, Dior, Hermès, Creed, Tom Ford, Prada, Armani, Versace, Kilian, Ganymede, Baccarat Rouge 540, Lattafa, Afnan, Sergio Nero «Адмиралъ», 4711).
* **Готовые пресеты полок:** *«Базовый джентльмен (Топ-5)»*, *«Современный люкс (8)»*, *«Арабский хит-парад»*, *«Нишевый ценитель»*, *«Русский характер»*.
* **Детектор гардеробных брешей (Wardrobe Gap):** если образ требует строгой дистанции, а на полке только сладкие клубные ароматы — система подберёт наименее диссонирующий вариант и вежливо подскажет, какого флакона не хватает в арсенале.
* **Сохранение в браузере:** полка автоматически сохраняется в `localStorage`.

### 6. 🎼 Каноническое 8D-Сольфеджио Стиля (Anyanov 8D Harmonic Engine)
Математический алгоритм сопоставления тактильных свойств гардероба ($L1–L4$) и ольфакторной физики аромата по **8 каноническим измерениям первоисточника**:
1. **Дистанция** (Обособленность / Субординация $\longleftrightarrow$ Интим / Сближение).
2. **Формальность** (Business Formal $\longleftrightarrow$ Casual).
3. **Власть** (Статус / Твёрдая власть $\longleftrightarrow$ Соблазн / Мягкая сила).
4. **Настроение** (Собранность / Фокус $\longleftrightarrow$ Лёгкость / Свобода).
5. **Диффузия** (Стойкая база / Шлейф $\longleftrightarrow$ Быстрая вспышка / Топ).
6. **Температура** (Тепло / Согревающий $\longleftrightarrow$ Холод / Освежающий).
7. **Время суток** (Вечер / Глубина $\longleftrightarrow$ День / Свет).
8. **Сезон** (Зима / Плотность $\longleftrightarrow$ Лето / Воздух).

Вычисляет взвешенное евклидово расстояние $D$, косинусное сходство $\cos(\theta)$ и диагностирует диссонансы (Clashes) с авторскими формулировками по каждой оси.

### 7. ⚛️ Периодическая система ольфакторных нот (Periodic Table of Notes)
* **Архитектурный предохранитель гармонии:** устраняет субъективное «я так чувствую», математически связывая молекулы аромата с тканями одежды.
* **4 периода ольфакторных элементов:** от летучих озоновых и цитрусовых молекул ($I$) до плотных смолистых удов и амбры ($IV$).
* **Матрица тканевого резонанса:** послойная валидация нот ($L1–L4$, AURA) с тканями аутфита (шерсть, кашемир, поплин, лен, твид, замша, кожа) и отсечение диссонансов (Clashes).
* **Интерактивная химическая таблица:** полноэкранный интерфейс в стиле Менделеева с фильтрацией по периодам, тканям и плотности.

### 8. 👑 Золотой Канон 21 (Эталоны 21×21)
* **Эталонная матрица 21 аромата:** по 5 эталонных флаконов на каждый квадрант плюс центральный камертон абсолютного баланса (*Bleu de Chanel EDP*).
* **Эталонная всесезонная капсула из 21 предмета:** $5\ (L4) + 7\ (L3) + 5\ (L2) + 4\ (L1) = 21$ предмет одежды на все случаи жизни.
* **Зеркало Духов и Луков:** витрина эталонных дуэтов с примеркой в один клик и пресетом для полки.

### 9. 🧭 Interactive Anyanov Board
* Интерактивная 2D-координатная доска с мгновенным откликом на клик/drag.
* Двухточечный радар в реальном времени: отображение положения собранного аутфита и нанесенного аромата.

### 10. 👔 Wardrobe OS Mannequin
* Визуализатор 4-слойной архитектуры гардероба ($L4$ Верхняя одежда, $L3$ Торс, $L2$ Брюки, $L1$ Обувь).
* Автоматический подбор фактур под уличную температуру (от -15°C до +35°C) и индекс формальности ($FI 1–3$).

### 11. 🎯 Экспресс-режим «Суть системы» (Core Principle View)
* **Принцип «0 ошибок»**: выбор одного из 4 фундаментальных жизненных архетипов (*Монументальный Статус*, *Собранность и Контроль*, *Магнетизм и Соблазн*, *Дневная Легкость*).
* **Готовый выверенный дуэт**: мгновенная компиляция гардероба и парфюмерного зеркала под выбранную цель с проверкой погоды.
* **Интерактивный переключатель «Полка / Эталон»**: мгновенный просмотр канонического эталона либо лучшего совпадения из личной полки с индикацией *Wardrobe Gap* при ольфакторных пробелах.

### 12. 🤖 Умный AI-Консьерж свободного ввода (Natural Language 8D Engine)
* **Калибровка стиля своими словами**: ввод любой жизненной ситуации на естественном языке (например: *«Свадьба лучшего друга за городом»*, *«Стратегические переговоры с инвестором в лобби отеля, +21°C»*, *«Романтическое свидание на Патриарших»*).
* **Семантический парсинг 5 категорий**: автоматическое выявление повода, характера отношений, локации, погоды/температуры и времени суток с нулевой задержкой.
* **Мгновенная проекция в 8D-вектор**: расчет координат $X$, $Y$, индекса формальности ($FI\ 1–3$) и температуры с наглядной карточкой распознанных факторов калибровки.

### 13. 🌐 AI-Движок живого поиска нот на Fragrantica (Gemini Live Search Grounding & Fast Parser)
* **Поиск формулы в реальном времени через Google Search Grounding**: запрос к Gemini API с нативным инструментом веб-поиска (`googleSearch: {}`) находит официальную карточку аромата на `fragrantica.com` / `fragrantica.ru`.
* **Устранение галлюцинаций LLM и отказ от хардкода**: система не выдумывает ноты «из головы» и не требует ручных правил — извлекаются аутентичные Top, Heart и Base ноты любого мирового релиза с аккуратным переводом на русский язык.
* **Мгновенный импорт текста из Fragrantica**: встроенный парсер скопированного блока пирамиды (на русском или английском языке) позволяет в 1 клик разложить ноты по слоям и пересчитать координаты на карте Аньянова без обращения к API.
* **Расширенная Периодическая таблица нот**: поддержка новейших ингредиентов и молекул (Акигалавуд, Амбервуд, Лабданум, Сомалийский ладан, Вирджинский кедр, Египетская герань, Итальянский мандарин).

### 14. 🧬 Биофизический движок гештальт-восприятия: Overdose Factor (Ω)
* **Преодоление «Bag-of-Notes Fallacy»**: переход от наивного среднего арифметического к психофизическим законам восприятия (Стивенс, Вебер — Фехнер, ольфакторная маскировка).
* **Реестр молекул-хищников (`OVERDOSE_DOMINANT_RULES`)**: компоненты с ультранизким порогом обнаружения (уд, берёзовый дёготь, ладан, супер-амбры, табак) получают нелинейный мультипликатор $\Omega \in [2.0 \dots 2.8]$, подавляя фоновые сахара.
* **Автоматическая термодинамическая коррекция (`effectiveTierFactor`)**: нейтрализация маркетинговых искажений пирамид, если тяжелые базовые смолы указаны в верхних нотах.
* **Безупречное позиционирование тяжелых хитов**: кейс *Mancera Red Tobacco* математически доказал точную посадку в Квадрант III ($SW: X = -0.13, Y = -0.62$, Темная власть).

### 🎯 Тетрада Воплощения (4 Выходных Канала)
> *«Система на входе получает интенцию, а на выходе рассчитывает, как эту интенцию реализовать через форму, фактуру, цвет и запах — гарантируя, что все 4 канала не противоречат друг другу.»*

1. **ФОРМА (Геометрия):** силуэт, посадка, крой, окат плеча (каркас vs soft-крой).
2. **ФАКТУРА (Материя):** плотность ткани (г/м), ворс, крутка (Super's / Fresco), драпируемость.
3. **ЦВЕТ (Оптика):** температура оттенка, контрастность, глубина тона и светопоглощение.
4. **ЗАПАХ (Аура):** скорость диффузии, давление пара, молекулярный вес нот (топ ↔ сердце ↔ база).

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/vsanyanov-ux/system-anyanov.git
   cd system-anyanov
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
   Откройте [http://localhost:5173](http://localhost:5173) в браузере.

4. **Проверка типов (TypeScript):**
   ```bash
   npm run typecheck
   ```

5. **Регрессионные тесты Google ADK Quality Flywheel:**
   ```bash
   npm run eval:adk
   ```

6. **Сборка для продакшена (оптимизированный бандл):**
   ```bash
   npm run build
   ```
